# Android Tools 设计

已确认：原生 Android 优先；多根工作区、子目录项目发现；设备树、文件树、应用管理和彩色 Logcat。使用 VS Code 原生树和 Webview，统一通过 ADB 按序列号操作。相比全 Webview 更易维护；相比终端封装能提供结构化交互。

文件编辑采用本地副本和显式上传；破坏性操作确认；所有设备命令绑定序列号；不提供 Root、私有目录和无线配对。项目扫描深度 4，可手动选目录；Gradle 构建使用工作区信任保护。真实包名优先从 output-metadata.json 获取，允许手动输入。

Logcat 有界缓冲、正则/文本/Tag/级别过滤，按包名动态跟踪 PID。清空视图和清除设备缓冲区分别执行。测试覆盖 shell 引号、设备解析、项目扫描、元数据和日志过滤；真机与 Extension Host 验证视本机环境可用性执行。
