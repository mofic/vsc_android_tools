# Android Device Tools

VS Code 安卓设备管理插件，支持原生 Android Gradle 项目和多根工作区。无需运行时 npm 依赖。

## 安装与运行

1. 安装 Android SDK Platform Tools，在终端确认 `adb devices -l` 能看到已授权设备。
2. 在 VS Code 执行 **Extensions: Install from VSIX…**，选择本仓库生成的 `android-device-tools-0.2.4.vsix`。
3. 打开左侧 Android Tools 图标，点击设备选中目标。ADB 不在 PATH 时设置 `androidTools.adbPath`。
4. 使用命令面板搜索 `Android Tools` 执行应用和文件操作；文件树提供右键菜单。

开发：本目录执行 `npm test` 和 `npm run check`；VS Code 打开目录后按 F5 启动 Extension Development Host。`npm run package` 生成 VSIX（首次需要网络下载打包工具）。

## 设备与文件

设备文件保留 VS Code 原生树。顶部显示设备和当前路径，支持后退、前进、上一级、路径跳转、最近目录；每个设备记住自己的最近路径。目录右键可“在此目录浏览”，文件和目录只显示适用菜单，支持复制设备路径、刷新选定目录和折叠全部。文件行显示大小，悬停查看修改时间和精确字节数；稳定节点 ID 用于刷新时保留展开/选择状态。读取失败会显示错误节点，与空目录区分。

打开设备副本后，编辑器右下角显示同步状态；修改后标记“待同步设备”。Ctrl/Cmd+S 只保存本地，点击状态栏或执行“保存编辑到设备”才上传。文件下载支持选择具体保存文件名，目录下载选择目标文件夹；传输通知显示 ADB 当前输出，成功后提示目标位置。

每 5 秒检查设备连接状态；设备状态不变时不重刷文件树。未授权和离线设备不能选中。默认浏览 `/sdcard`，文件列表顶部提供“返回上一级”入口，根目录 `/` 时隐藏；即使当前目录读取失败也保留返回入口。使用“跳转设备目录”访问其他 ADB 可读目录。文件树支持创建、重命名、删除、上传和下载文件/文件夹。浏览时只读取当前层名称、类型和链接元数据，不递归扫描或下载文件内容。目录按需加载并缓存（最多 128 项），重复和并发请求会复用结果；手动刷新、设备切换/断开、新建/重命名/删除/上传后更新相关目录缓存。设备上由其他应用修改目录后，请点击刷新。包含隐藏文件；名称可列出但属性不可读取的条目使用锁图标，展开时显示实际权限错误。

侧栏“打开当前应用目录”直达私有目录 `/data/data/<applicationId>`，需要 Root（支持 Root adbd 或 `su -c`，请在设备上授权 ADB shell）。成功后文件树标记 ROOT，浏览和文件操作使用 Root；应用管理、Logcat 仍使用普通 ADB。包名优先使用当前项目已选变体，否则从 APK 识别或手动输入。目录不存在会提示，不自动创建。私有文件传输通过仅 shell 可访问的临时目录中转并清理；写回已有文件保留属主、权限及 SELinux 标签，新文件继承父目录属主和标签。Root 上传不接受本地符号链接，需选择实际文件。

符号链接使用独立的文件/文件夹链接图标，并显示目标路径。目录链接可展开，文件链接打开解析后的目标文件。文件打开操作进入编辑器；重复打开复用同一份本地编辑副本，不重复拉取或弹出下载提示。“下载”仍是独立右键操作。编辑后执行 **保存编辑到设备**，确认覆盖原文件。编辑副本绑定下载时的设备，即使切换设备也不会写错设备。退出扩展后删除临时副本，请及时上传或另存为。上传/下载文件夹会合并目录并覆盖同名文件，操作前有确认；取消可能留下部分文件，不支持事务回滚。

普通 ADB 无法读取其他应用私有目录，权限错误会提示；不支持 Root、run-as、无线配对。文件名中的换行符不支持。大文件请使用下载而非文本编辑。

## 原生项目与应用

左侧 **Android Tools → 项目应用** 提供直接操作入口，顶部显示当前项目、设备和 applicationId。点击三项内容可切换；下方依次提供运行、清除数据并运行、启动、停止、清除数据、卸载、撤销权限、应用设置。“应用设置”打开所选设备上当前包名的系统应用详情页。运行会编译当前项目、安装并启动；清除数据并运行在编译完成后请求确认，再安装、清除数据并启动；启动仅打开已安装应用。安装现有 APK 的命令面板入口继续保留。已确认的包名自动复用，需换变体时点击包名重新选择。未选择目标时会引导选择；执行期间按钮禁用，危险操作仍需确认。命令面板入口继续保留。

支持直接打开文件夹和多根 `.code-workspace`。从各根目录扫描 `settings.gradle` / `settings.gradle.kts`，默认深度 4，可设置 `androidTools.scanDepth`；忽略 `.git`、`.gradle`、`build` 等目录。发现一个项目自动选择；多个项目手动选择并在工作区记忆，支持手动选目录。

“构建并安装启动”使用项目 Gradle Wrapper，可选择/输入模块和变体构建任务（默认 `:app:assembleDebug`）。构建后选择 APK 元数据，获取真实 applicationId，包括 flavor 和 applicationIdSuffix。需预先配置 JDK/Android SDK，且项目 Wrapper 可用。安装已有 APK 支持多选 APK，通过 `install-multiple` 安装拆分包。构建流程选择含拆分过滤条件的 APK 时会提示改用通用 APK 或手动选择完整拆分包。

启动、停止、卸载、清数据和撤销权限会确认 applicationId；优先使用构建产物包名，没有产物可以手动输入。卸载、清数据、权限撤销有额外确认。撤销权限仅针对当前 Android 用户、所选应用已授予的运行时权限；系统固定权限等可能失败，详情在输出面板 Android Tools。不会执行全设备权限重置。

构建、设备写入和应用操作要求工作区已信任。

## Logcat

### Studio 风格查询与阅读

主查询栏支持以下写法（Enter 应用，输入时提供常见查询提示）：

```text
package:mine level:ERROR -tag:Choreographer
(tag:Network | tag:Database) & message:timeout
process:remote age:5m
message~:"failed.*request" name:"请求错误"
is:crash
```

支持 `package`、`process`、`tag`、`message`、`line`、`level`、`age`、`is`、`name`。`package:mine` 使用当前所选项目的 applicationId，缺少时会引导选择；离线日志不支持它。`-tag:` 等否定和 `tag~:` 等正则可用于文本字段；带空格或正则括号/运算符的值请加引号。支持 `&`、`|` 和括号，AND 优先于 OR；空格默认为 AND，同一隐式条件组内重复正向字段默认 OR。该规则是明确限定的 Studio 风格子集，不承诺所有 Studio 查询语法完全兼容。`age` 使用主机时间及日志中推断的年份，历史导入或设备时钟不同可能影响结果。`is:crash` / `is:stacktrace` 为文本特征匹配。

更多过滤中保留旧版关键词/Tag/包名/正则条件，与主查询共同生效；旧过滤历史仍可使用。可命名收藏、选择应用或移除收藏，最近查询与收藏各保留 20 条。无效查询会标记错误并保留上次有效过滤。

标准 threadtime 日志按时间、PID:TID、包名/进程、级别、Tag、消息分列。工具栏“精简”隐藏时间和 PID 列，窄窗口自动精简；普通文本日志按原文展示。新日志增量追加，缓冲淘汰时复用仍保留的行，避免重绘打断选区。向上滚动或选择日志解除跟随，滚到末尾或点击“回到最新日志”恢复；暂停时显示新增条数。搜索保持独立，重连保留当前过滤、换行和视图选项。


顶部使用紧凑图标工具栏，悬停查看说明。Tag、包名、最近配置收在“更多过滤条件”；新建标签页、分屏、导入/导出、复制、重连、清除设备日志收在“更多操作”。日志内搜索默认隐藏，点击放大镜或 Ctrl/Cmd+F 打开，点击关闭或 Escape 收起并清除高亮。关键词、Tag 和包名输入后可按 Enter 应用过滤。状态信息位于底部。

支持多个原生 VS Code 标签页，每页标题带独立编号。点击 Logcat 内“新建标签页”可为同一设备或离线日志多开；“分屏”在旁边编辑器组打开，便于对比。也可多次执行“打开 Logcat”查看不同设备。各页过滤、日志缓冲、暂停和清屏独立；关闭一页仅停止该页采集。新建页从默认过滤条件开始。注意“清除设备日志”操作作用于设备缓冲区，会影响该设备的所有实时页。

每个面板绑定自己的设备；可同时打开多个设备面板。按 V/D/I/W/E/F 级别着色，支持最低级别、Tag、关键词、正则、包名过滤。包名每 1.5 秒重新查询进程表，跟随应用重启，同时包含 `:remote` 等子进程。

最多保留最近 10000 行。暂停仅暂停显示，后台继续更新有界缓冲。支持自动滚动、复制/导出过滤后的缓冲日志；“清空视图”只清本面板，“清除设备日志”会确认后清设备缓冲区。断连后点击“重连”。正则用于本地过滤，请避免复杂回溯表达式。

## 验证范围

`node:test` 覆盖路径与 shell 引号、设备状态、多根扫描与深度、APK 元数据、日志过滤、进程失败。自动化不替代真机验证；实际安装、文件传输、权限和 Gradle 构建受设备/项目环境影响。

### 包名显示与换行

实时日志行首显示当前设备 PID 对应的包名/进程名，底部独立显示当前生效的包名过滤，不会被连接状态提示覆盖。进程表每 1.5 秒更新；无法识别时显示“未知进程”，导入日志没有设备进程映射时不猜测包名。该标注依据采集时的当前进程表，不能保证历史日志中已退出或 PID 重用进程的归属；复制/导出仍保留原始日志文本。

主栏“换行”勾选时自动换行，取消后按单行显示并支持水平滚动。每个标签页独立控制，切换与日志刷新不会改变模式。

### 日志内搜索

“日志内搜索”在当前页已显示的日志中查找文本，忽略大小写，高亮所有匹配并显示当前位置/总数，不隐藏其他行，也不保存到过滤历史。实时页和导入离线页均支持。使用 ↑/↓ 或 Enter/Shift+Enter 循环切换匹配，Ctrl/Cmd+F 聚焦搜索，Escape 清空。输入搜索内容会关闭自动滚动，避免新日志打断定位；需要继续跟随日志时重新勾选“自动滚动”。搜索范围受当前过滤条件和最近 10000 行缓冲上限约束。

### 截屏与录屏

实时 Logcat 顶部提供截屏、录屏图标（悬停显示“设备截屏”和“开始录屏 / 停止录屏”），绑定该标签页设备。先选择本地保存路径，取消不会启动采集。截屏保存 PNG 后用 VS Code 打开；录屏保存 MP4，不含音频，最长 180 秒后自动结束并保存。关闭标签页会尝试停止该页发起的录屏并完成保存；同一设备同一时间只能由一个标签页录屏，不同设备可分别录制。离线页禁用采集，工作区需已信任。

保存成功或失败后立即恢复按钮，不等待关闭通知。停止后最多等待设备进程 15 秒，超时会报错并保留设备临时文件；下载仍受 ADB 命令超时限制。停止录屏只向本次启动的设备进程发送 SIGINT，不会批量终止其他录屏进程。本地下载通过临时文件和同目录重命名完成；传输失败不会覆盖原有本地文件，设备文件保留，错误提示给出恢复路径。退出 VS Code 可能中断下载，请先停止并确认保存；设备录制仍有 180 秒时间上限。

实现使用 Android 原生 `screencap` / `screenrecord`：[官方 ADB 文档](https://developer.android.com/tools/adb)。

### 最近过滤配置

点击“应用过滤”会自动保存最近 20 条有效配置（级别、关键词、正则开关、Tag、包名），相同配置去重并移到最前。从“最近过滤”下拉框选择后立即填入并应用。历史保存在当前 VS Code 配置的扩展存储中，重启后保留，工作区与 Logcat 标签页共享；其他标签页仅更新历史列表，不改变正在使用的过滤条件。离线使用含包名的配置时会跳过包名过滤，并保留历史中的完整配置。

### 导入离线日志

Logcat 顶部“更多操作”中点击“导入日志”，或从命令面板执行 **Android Tools: 导入 Logcat 日志**（设备视图的更多操作菜单也可进入），选择本地 `.log` / `.txt` 文件，无需连接设备。每次导入新开离线面板，不覆盖正在采集的实时日志。

支持 UTF-8（含 BOM）、CRLF 和 ANSI 颜色转义清理；标准 `logcat -v threadtime` 及本插件导出的日志可识别级别、Tag 和 PID，其他行按原文显示。单文件最多 32MB，超过 10000 行时只保留末尾并提示。离线模式支持级别、关键词、正则、Tag 过滤和复制/导出；没有设备进程映射，因此禁用包名过滤、重连、暂停采集和清除设备日志。UTF-16/二进制文件请先转为 UTF-8 文本。

## Git

仓库为本地 Git 管理。远程托管时添加你的仓库：

```sh
git remote add origin <仓库地址>
git push -u origin main
```
